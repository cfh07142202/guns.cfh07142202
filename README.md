✰𝖈𝖋𝖍✰ — Personal Link Tree

A small personal link tree I made using HTML and CSS.

It has my profile, a few links, and a glass-style design with an animated background. Nothing complicated, just a simple page to put my links in one place.

Features

🖼️ Profile card with username and profile picture

🔗 Links to my GitHub and YouTube Music

🌌 Animated GIF background

✨ Simple hover effects on the icons

📱 Works across different screen sizes

♿ Reduced-motion support with a static background

🧱 Built with plain HTML and CSS

Built With

HTML5

CSS3

Font Awesome

Project Structure
├── index.html        # Main webpage
├── style.css         # Website styling
└── images/           # Backgrounds, profile picture and icons

Hosting

The website is hosted on Netlify and connected to this GitHub repository.

Any changes pushed to the main branch can be deployed automatically.
